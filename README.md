# Поиск критических объектов электрической сети в ГИС QGIS

Программа для консоли Python в QGIS. Она строит топологическую модель электрической сети по открытым данным NVE (Норвегия), моделирует отказ любого элемента и анализ N-1. Обесточенные участки находятся инкрементальным поиском в ширину, после чего элементы ранжируются по критичности.

## Состав

| Папка / файл | Что это |
|---|---|
| `program/outage_qgis.py` | Программа: построение топологии, анализ отказа, анализ N-1, панель оператора в QGIS |
| `program/Руководство_анализ_отключений.pdf` (.docx) | Методические указания по работе с программой |
| `program/results/` | Примеры результатов (сценарии отключений, анализ N-1 по Норвегии) |
| `layers/elektro_topo.gpkg` | Готовая топологическая модель фрагмента сети (для быстрой проверки) |
| `layers/elektro_topo_norge.zip.part00…part06` | Готовая топологическая модель всей сети Норвегии, разбитая на 7 частей |
| `layers/join_norge.bat` | Скрипт сборки частей в один архив |
| `layers/*_topology_report.txt` | Отчёты о построении топологии (параметры и статистика) |

Слои GeoPackage (EPSG:25833):

- `net_edges` — рёбра (участки линий, шины подстанций);
- `net_nodes` — узлы (подстанции, внешние источники, ответвления, концы линий);
- `net_masts` — опоры с привязкой к рёбрам.

Модель Норвегии содержит 154 722 ребра, 159 543 узла и 734 293 опоры.

## Как скачать и собрать модель Норвегии

1. Нажмите **Code → Download ZIP** и распакуйте архив репозитория.
2. В папке `layers` запустите `join_norge.bat`. Он склеит части в файл `elektro_topo_norge.zip`.
3. Распакуйте `elektro_topo_norge.zip`, внутри лежит `elektro_topo_norge.gpkg` (≈ 160 МБ).

Без Windows части можно склеить так: `cat elektro_topo_norge.zip.part0* > elektro_topo_norge.zip`.

## Запуск

1. Положите `outage_qgis.py` и файлы `.gpkg` в одну папку, например `C:\outage_tool`.
2. В начале `outage_qgis.py` укажите пути к моделям в словаре `PROFILES` (ключ `gpkg`). Профиль выбирается переменной `PROFILE` (`'norge'` или `'region'`).
3. Откройте QGIS 3.x, затем **Модули → Консоль Python → Показать редактор**. Откройте `outage_qgis.py` и запустите его.
4. Слои загрузятся из GeoPackage, и появится панель оператора. Дальнейшие шаги описаны в руководстве `program/Руководство_анализ_отключений.pdf`.

Чтобы построить модель заново из исходных данных, скачайте набор NVE «Nettanlegg» (FileGDB, EPSG:25833), укажите путь в `PROFILES` (ключ `src`) и задайте `REBUILD = True`.
