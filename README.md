# ВКР: поиск критических объектов электрической сети на основе топологической модели в ГИС QGIS

Выпускная квалификационная работа «Повышение оперативности анализа данных об аварийных отключениях электрической сети на основе её топологической модели в ГИС QGIS (на примере электросети Норвегии)».

Работа посвящена поиску критических (наиболее опасных) объектов сети, то есть элементов, отказ которых обесточивает наибольшую её часть. Топологическая модель строится автоматически по открытым данным NVE. Отказ каждого элемента моделируется инкрементальным поиском в ширину (анализ N-1), после чего элементы ранжируются по показателю критичности.

## Основные результаты

- Топологическая модель электросети Норвегии: 154 722 ребра, 159 543 узла.
- Анализ отказа одного элемента занимает 3,3 мс (полный обход сети — 116,6 мс).
- Поиск критических объектов (анализ N-1) занимает 9,3 с для 1 595 подстанций и 4,5 мин для 97 126 линий. Вручную на это ушло бы около 237 ч и 11 600 ч соответственно.
- Наиболее критичный объект — подстанция NORSENGA: её отказ обесточивает 377,6 км линий.

## Как скачать

Нажмите **Code → Download ZIP** на странице репозитория или откройте нужный файл и нажмите **Download raw file**.

## Запуск программы

1. Откройте QGIS 3.x, затем **Модули → Консоль Python**.
2. Загрузите и запустите `program/outage_qgis.py`.
3. Подробности описаны в руководстве `program/Руководство_анализ_отключений.pdf`.

Исходные данные — открытый набор NVE (Norges vassdrags- og energidirektorat), файл «Nettanlegg».
